# Online Order Management System

## Project Overview

This project focuses on designing an Online Order Management System to automate the product ordering process and reduce manual intervention.

## Project Objective

The objective is to design and implement an online ordering management system that enables customers to order products, check product availability, process orders, and track orders online through the portal.

The project aims to reduce manual work by 90% and launch the application within two quarters.
